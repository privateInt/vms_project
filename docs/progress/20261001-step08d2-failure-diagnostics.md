## 이번 수정

리허설 도구와 단위 테스트를 수정하고 이 문서를 추가한다. 제품 API·스키마·운영 구성·기존 프로젝트 명세와 리허설 순서는 유지한다. 이번 단위는 실패 원인 확인에 필요한 진단 정보 보완이며, 아직 확인되지 않은 원인에 대한 제품 수정이나 운영 활성화를 포함하지 않는다.

실패 JSON 및 0600 개인 보고서에 다음을 추가한다.

- error_type: 사전 정의한 예외 분류. 예: ValueError, KeyError, URLError, TimeoutError.
- failure_location: 알려진 프로젝트 도구의 파일명·함수명·줄 번호. 해당 프레임이 없으면 생략한다.
- python_version: 서버 실행 Python의 major.minor.micro 버전.

예외 메시지·인자·지역 변수·요청/응답 본문·토큰·DSN·전체 경로·원문 traceback은 출력하지 않는다. 기존 안전한 오류 코드 형식, 실패 시 보고서 무효화, activation 잠금, 시험 자원 정리 절차를 유지한다.
